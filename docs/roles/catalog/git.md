# git — Git for Windows

Git for Windows, machine-wide from the Inno Setup installer, `registry` provider. No
variables.

## Notes

- `searchName` is the exact `DisplayName` `Git` (no glob): Git for Windows registers
  under that name at every version.
- Installed and removed with the installer's defaults (`/VERYSILENT /NORESTART
  /NOCANCEL /SP-`): components, PATH mode and line-ending setting are upstream's.
