# netbeans — Apache NetBeans

Apache NetBeans from the [codelerity](https://github.com/codelerity/netbeans-packages)
Inno Setup package, which bundles a JDK: no separate Java install is needed.
`registry` provider, detected as `Apache NetBeans version *`. No variables.

## Notes

- The schema declares no shortcuts (a block is left commented out in
  `vars/main.yaml`); the installer's own are used.
