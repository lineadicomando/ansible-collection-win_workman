# python310 — Python 3.10

Python 3.10 for all users in `%ProgramFiles%\Python310`; same design as
[python314](python314.md) (Burn bundle detected through its `Core Interpreter` MSI,
`bundle_parts` removal, no launcher, public desktop shortcuts). No variables.

**Deprecated.** python.org publishes no Windows installer past 3.10.11, so the
role cannot be updated. End of life was 2026-10-31; the role prints a warning at every
run. Migrate to `python314` or `python315`.
