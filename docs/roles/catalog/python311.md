# python311 — Python 3.11

Python 3.11 for all users in `%ProgramFiles%\Python311`; same design as
[python314](python314.md) (Burn bundle detected through its `Core Interpreter` MSI,
`bundle_parts` removal, no launcher, public desktop shortcuts). No variables.

**Deprecated.** Security-fix-only: python.org publishes no Windows installer past
3.11.9, so the role cannot be updated. End of life 2027-10-31; the role prints a
warning at every run. Migrate to `python314` or `python315`.
