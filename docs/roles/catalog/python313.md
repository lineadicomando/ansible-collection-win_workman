# python313 — Python 3.13

Python 3.13 for all users in `%ProgramFiles%\Python313`; same design as
[python314](python314.md) (Burn bundle detected through its `Core Interpreter` MSI,
`bundle_parts` removal, no launcher, public desktop shortcuts). No variables.

3.13.17 is the last release with a Windows installer: python.org has 3.13.18 as source
only (checked 2026-11-28). The role has no deprecation warning yet, unlike
`python310`–`python312`.
